## 高效学习顺序

1. 先读每篇开头的“一页速记”，建立术语与公式框架。
2. 学完 Chapter 1 Part 2 后完成 Tutorial 1，重点掌握 store-and-forward、circuit switching 与 statistical multiplexing。
3. 用 Tutorial 2 集中训练各类 delay 的拆分与单位换算。
4. 阅读 Chapter 2 Part 1，把 process、socket、IP、port、TCP/UDP 与 HTTP 串成完整通信过程。
5. 闭卷完成各章“30 秒自测”，答错的内容回到对应小节复习。

本课程从 Internet 的组成与网络性能出发，逐步进入协议分层、应用层通信与典型网络协议。
